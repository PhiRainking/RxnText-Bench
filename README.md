# RxnText-Bench

A reproducible benchmark for **reaction-condition extraction** from chemical text: rule-based pipeline vs. schema-constrained large language model (DeepSeek Flash).

**Paper:** *Benchmarking Schema-Constrained Large Language Models against Rule-Based Pipelines for Reaction-Condition Extraction from Chemical Text* — under review (2026).

## Files
| File | Description |
|---|---|
| `pipeline.py` | Full pipeline: sentence rendering → realism noise → regex extraction → LLM extraction (JSON mode) → metrics → figure |
| `seed_reactions.py` | 100 curated reaction records (gold standard) + synonym/resolution maps |
| `results.json` | Raw per-instance predictions and scores (regex vs DeepSeek Flash) |
| `fig1.svg` / `fig1_zh.svg` | Figure 1 (English / Chinese) |

## Quickstart (Python 3.11+, standard library only)
```bash
python pipeline.py --variants 13                 # rule-based baseline (seconds)
LLM_API_KEY=sk-... LLM_API_BASE=https://api.deepseek.com LLM_MODEL=deepseek-v4-flash \
  python pipeline.py --variants 13               # full run (~8 min, 20 workers)
```

## Headline results (1,300 instances = 100 reactions × 13 renderings)
| | rule pipeline | DeepSeek Flash |
|---|---|---|
| mean field accuracy | 69.9% | **92.6%** |
| instance-level exact | 3.5% | **70.5%** |

McNemar χ² = 863.9, p < 10⁻¹⁵. Error taxonomy: 167 of the 231 catalyst-field errors are role-ontology boundary disagreements; re-scoring under a three-role ontology raises instance-level exactness to 80.1%. Every number is regenerated by a single command from the released raw predictions.

## Data notes
- Synthetic gold benchmark, zero manual annotation: each reaction record is rendered into patent-style sentences with a controlled realism noise layer (abbreviations, full systematic names, "overnight" durations).
- `results.json` contains all raw predictions; no manual adjustment is possible by construction.
